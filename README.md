# 🌮 The Little Taco Shop Website

A charming and delicious website for The Little Taco Shop, built with HTML, CSS, and a passion for tacos!

## 📋 Project Description

The Little Taco Shop Website is a multi-page website showcasing a local taco restaurant. Founded in 2022, this project demonstrates a love for tacos and provides customers with essential information about the shop, including menu items, store hours, and contact details.

## ✨ Features

- **Home Page** - Welcome page with shop information and taco trivia
- **Menu Page** - Interactive pricing table for crunchy and soft tacos
- **Store Hours** - Easy-to-read schedule displaying operating hours
- **Contact Us** - Contact form and location information
- **Responsive Navigation** - Consistent navigation menu across all pages
- **Semantic HTML** - Properly structured HTML5 markup
- **Accessible Design** - ARIA labels and proper heading hierarchy

## 🛠️ Technologies Used

- **HTML5** - Semantic markup and structure
- **CSS3** - Styling and layout
- **WebP Images** - Optimized image format for faster loading

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- No server required - runs locally

### Installation

1. Clone or download this repository
2. Navigate to the project folder:
   ```
   cd Taco-shop-website-project
   ```
3. Open `web.html` in your web browser

## 📖 Usage

- **Home Page** (`web.html`) - Learn about The Little Taco Shop and browse the menu
- **Store Hours** (`time.html`) - Check when we're open
- **Contact Us** (`contact.html`) - Send a message or find our location
